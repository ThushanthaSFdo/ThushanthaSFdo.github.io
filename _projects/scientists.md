## Background

This project is designed to educate users about influential scientists through an immersive augmented reality experience. By leveraging ARKit and SceneKit, the app allows users to interact with digital content overlaid on real-world images. The application targets educational purposes, making learning about science and history engaging and interactive.

The scientists' data is stored in a JSON file, which includes their names, biographies, and country flags. This modular approach enables easy updates and additions to the dataset without altering the app's core functionality. The user interface is designed to be intuitive, with clear text overlays that provide information in a visually appealing manner.

The project not only aims to enhance knowledge about scientific contributions but also seeks to promote interest in STEM fields among users of all ages. Through this innovative use of technology, the app bridges the gap between education and entertainment, making learning a fun and interactive experience.
